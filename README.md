# LGB Relationship Status across Europe
### Interactive 2020 FRA Survey Report

This interactive Power BI report analyzes relationship status, cohabitation forms, and single life trends within the LGB community across European nations in the year 2020. 

The data explores four key demographic groups:
*   **Lesbian women**
*   **Gay men**
*   **Bisexual women**
*   **Bisexual men**

The report examines how these partnership patterns shift based on age, location, and the level of openness in daily life. 

### Primary Objective
The primary objective of this project is to provide a clear statistical comparison between the **Czech Republic** and the **European Union average**.

### Data Visualization & Mapping
For the European continent visualization, a custom map shape was utilized:
*   The base map was generated using [GeoJSON Maps](https://geojson-maps.kyd.au/).
*   **Map editing:** The map data was manually adjusted to remove French Guiana. This unnecessary location was removed to optimize the visual scale, ensuring the European continent remains large and easily readable for the user.

### Data Source
Primary data is sourced from the official FRA LGBTI Survey (2020).
